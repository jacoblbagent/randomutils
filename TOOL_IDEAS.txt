RandomUtils — tool idea inventory
=================================

Every tool listed here MUST run entirely in the end-user's browser, on their own
device. No server of ours, no upload, no account, no backend of any kind.

Constraint rules used to build this list:
  - Client-side only: computation happens in the browser (JS/WebAssembly/Canvas/
    Web Audio/Web Crypto/WebCodecs/library-in-a-bundle).
  - No tool whose core function is to query a third party over the network
    (DNS, WHOIS, IP geolocation, SSL inspection, redirect checking, HTTP
    fetching, live currency rates, hosted inference).
  - "Asset fetch" tools are client-side but pull a font/icon file over the
    network; flagged inline.
  - "On-device model" tools download an ML model once and then run locally; no
    server of ours is involved. Flagged inline.

Flagged entries:
  background remover        on-device model
  karaoke vocal remover     on-device model
  OCR PDF                   on-device tesseract
  Google Fonts previewer    asset fetch
  icon browser              asset fetch

Shipped — live on randomutils.com today, one tool per route:
  TS->MP4                            /ts-to-mp4
  MOV->MP4                           /mov-to-mp4
  video->audio (MP3/WAV/M4A)         /audio-extract

  The three above are marked [shipped] in the list below; everything else in this
  file is still a candidate, not a promise. A new tool is appended to
  src/data/tools.ts, given a route in src/App.tsx and a flag in
  src/config/flags.ts — see the "Adding a tool" section of README.md.

Excluded from the hub (cannot be client-side-only):
  currency / FX converter          needs live exchange rates
  handwriting-to-text              hosted inference
  pandoc-style converter           no browser pandoc
  DNS lookup / WHOIS / IP geo      network queries
  SSL checker / redirect checker   network queries
  HTTP header / URL fetch tools    network queries
  CORS testing / endpoint probes   network queries
