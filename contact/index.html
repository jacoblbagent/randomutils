Report a conversion that came out wrong

Include as much of this as you can, and it can usually be worked out without the file:

  • Which tool — TS → MP4, MOV → MP4 or Video → Audio.
  • The source format and roughly how the file was made (a DVR recording, an iPhone clip, a camera export).
  • Your browser and version, and whether you are on desktop or mobile.
  • What you expected and what you got — a file that will not play, no audio, a stall, an error message.
  • Anything the browser's console reported. Open developer tools (F12) before you start the conversion and copy the error out.

If a file is small and you can share it, say so first — but never send anything private or confidential. Files are not needed to answer most questions.

Formats, features and ideas

Wanting another format or a missing option is a good reason to write. A short note on the format and what you need it for is enough; format requests are what most of these tools started as.
