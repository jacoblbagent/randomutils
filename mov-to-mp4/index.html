About this tool

What a .mov file is

A .mov file is a QuickTime movie: one of the oldest surviving media containers, and still the one Apple’s cameras, phones and editors write by default. The container is organized much like an MP4 — it is read from its header, which is why a .mov seeks and scrubs cleanly — but it is far more permissive about what it will carry. That permissiveness is the whole story here: two files both ending in .mov can be as different inside as a text file and a photograph.

What copies and what gets re-encoded

The Auto method keeps whatever an MP4 player will accept, and re-encodes only the rest:

  • Copied untouched — H.264 and HEVC video, and AAC or MP3 audio. This covers what an iPhone, an iPad or a screen recording produces, which is the overwhelming majority of what people drop in. A copy is lossless and takes seconds.
  • Re-encoded — professional and camera codecs MP4 players refuse: ProRes, DV and Motion JPEG video, and PCM, ALAC and similar audio. These are high-quality formats that simply have no place in the MP4 specification, so the video is transcoded to H.264 and the audio to AAC.

If you would rather not transcode anything, force Stream copy and let a ProRes or PCM file fail rather than be converted. If you want one file that will play anywhere without checking first, force Re-encode.

Where these .mov files come from

  • iPhone, iPad and Mac screen recordings, which are H.264 or HEVC and copy straight across.
  • Camera and camcorder exports, often ProRes, which are converted.
  • Video-editing exports — Final Cut, Premiere, DaVinci — which can be any of the above depending on how they were set to render.
  • Old QuickTime movies, where the video may be DV or an even earlier codec.

There is no minimum size here, unlike the .ts tool: a .mov is already a finished file, and a two-second clip is a normal thing to convert.

If something goes wrong

  • The MP4 has silent, unfollowable sound or no audio at all. The audio was PCM or ALAC, which MP4 cannot carry. Re-run it with Re-encode.
  • “Stream copy failed.” The file is ProRes, DV or similar — expected, and exactly what Auto fixes.
  • The picture is very dark or washed out. Some camera footage carries a colour profile MP4 players read differently. A Re-encode usually normalizes it.
  • A large file stops part-way. Input and output both sit in the page’s memory; a single movie over roughly 2 GB may exhaust it.
  • The file is a .mov but nothing happens. Check it is really a movie and not a mislabelled export; if in doubt, open it once in a player.
