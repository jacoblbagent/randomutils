About this tool

What a .ts file is

A .ts file is an MPEG transport stream: the container tuners write because it survives a lossy signal. It has no index at the head like MP4, just a continuous run of small fixed-size packets, so a receiver can tune in mid-stream. That is why a recording plays in VLC and badly, or not at all, in QuickTime, on most phones, and in editors that expect a seekable file. The video inside is fine; the container is the problem, and this tool moves it into MP4.

Recordings usually come from a network tuner such as an HDHomeRun, a cable box or DVR, or an over-the-air capture. .mts and .m2ts are the same family from AVCHD camcorders and Blu-ray, and this tool takes all three.

Stream copy or re-encode?

Auto is right almost every time: it copies video and audio untouched where an MP4 can hold them and re-encodes only what it cannot. A copy is lossless and limited by disk rather than processor, so a two-hour recording finishes in seconds.

  • Stream copy: force it when the recording is H.264 or HEVC with AAC and you want the fastest, identical result. If the video cannot sit in an MP4 it fails rather than re-encoding silently.
  • Re-encode: H.264 + AAC, playable anywhere, but slow, roughly real time on a laptop, and it discards the original quality. Use it when Auto produced a file that still will not play.

The 50 MB floor, and DVR .star files

  • Any .ts under 50 MB is skipped. Files that small are almost always stubs, ad-break fragments or index scraps. For a genuine smaller clip, see the contact page.
  • A .star file sitting next to a recording (hdz_0000.ts.star and the like) is a DVR sidecar naming the programme. Drop it in with the video and it is never converted itself; it flags the matching row and rides into the output name.
  • A same-named .jpg becomes that row’s thumbnail.

If something goes wrong

  • The MP4 plays but has no sound. The audio was probably AC-3, which MP4 players commonly refuse. Re-run that file with Re-encode.
  • The picture shows comb-like lines on movement. The source is interlaced. Re-encode de-interlaces; a stream copy cannot.
  • “Stream copy failed.” The video inside the stream is not MP4-legal. Auto or Re-encode handles it.
  • A very large file stops part-way. Input and output sit in page memory, so a recording over roughly 2 GB may run out of room. Split it first.
  • Dropping a file does nothing. Check the extension is .ts, .mts or .m2ts, and that the file is over 50 MB.
